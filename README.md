# Closr (by Tyranox)

**Local-first, ultra-fast peer-to-peer file, folder, and text sharing over Wi-Fi.**  
Mutual TLS 1.3 encrypted &bull; 8-digit SAS pairing &bull; Zero cloud &bull; Zero accounts.

---

## Platforms
- **Windows (x64)**: Available today via **Microsoft Store** (MSIX) and **Direct Installer / Portable ZIP** (`Closr-Setup-v*-x64.exe` / `Closr-v*-Windows-x64.zip`).
- **Android**: Planned / companion mobile release (see [Releases](https://github.com/TyranoxHQ/closr/releases)).

---

## Free vs. Pro
- **Closr Free**: Full local mDNS discovery, 8-digit SAS pairing, and peer-to-peer transfers up to **1 MB per file**, **1 file per transfer**, **40 characters** per quick text message, **1 recipient** per transfer, **1 trusted peer**, and **0 device groups**.
- **Closr Pro**: Unlocks unlimited file sizes, multi-file & folder batch transfers, unlimited quick text length, simultaneous multi-recipient transfers & device groups, and unlimited trusted peers with optional auto-accept.
  - **Microsoft Store build**: Optional one-time **$5** Microsoft Store in-app purchase (valid on Windows PCs only).
  - **Direct build**: Lifetime license key (up to 3 devices).
