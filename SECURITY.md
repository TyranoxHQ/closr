# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability in **Closr** (by **Tyranox**), please **do not** open a public GitHub issue.

Email your report privately to **khthisald@gmail.com** with:
- The affected version and distribution (Microsoft Store MSIX, Direct Installer, or Android).
- Clear steps to reproduce the issue.

We will acknowledge your report and work on a fix before public disclosure.
